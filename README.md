# BUCAZU — бюджет жизни за границей

[Живой сайт](https://vlad1ewt4.github.io/bukazu-budget/)

## Сценарий пользователя

1. Ввести накопления и ежемесячный доход на руки, который сохранится после переезда (рубли).
2. При необходимости раскрыть настройки: срок 3, 6 или 12 месяцев и регулярные обязательства.
3. Нажать «Рассчитать». Появятся девять альтернативных направлений, отсортированных по месячным расходам. Каждое использует весь бюджет пользователя независимо от остальных.
4. Раскрыть «На что уходят деньги»: готовая разбивка, источники, исходные цены и даты, состав корзины и помесячные остатки. Расходы и курсы в интерфейсе не редактируются.

При изменении своих данных нужно снова нажать кнопку. Старые результаты сохраняют исходные суммы и помечаются как требующие пересчёта. Суммы не сохраняются на сервере или в URL, не отправляются внешним сервисам. Аналитики и внешних шрифтов нет.

Направления: Дананг, Нячанг, Бангкок, Бали, Куала-Лумпур, Тбилиси, Ереван, Белград, Анталья — 9 направлений в 8 странах.

## Что считается

Сценарий рассчитан на одного взрослого, квартиру с одной спальней, фиксированную продуктовую корзину плюс 20 приёмов пищи и 12 кофе в кафе, 20 поездок на такси по 5 км. Коммунальные услуги, домашний интернет и мобильная связь включены отдельно от аренды. Площадь коммунального ориентира явно указана: небольшая квартира, где есть эта категория, иначе 85 м² без выдуманного пересчёта на меньшую площадь.

Месячные расходы `M = round(сумма 6 категорий × 1,10) + обязательства`. Резерв равен одному месяцу M. Доход поступает в конце месяца, расходы оплачиваются до него. При горизонте n и доходе I необходимые накопления на жизнь и резерв:

`R = M + max(M, 2M − I, …, nM − (n−1)I)`.

Остаток от дохода: `I − M`; дефицит накоплений: `max(0, R − S)`. Высокий доход не отменяет денег на первый месяц и резерв. При нулевом доходе нужны `(n+1)M`. Аренда не считается дважды; расчёт ведётся в целых копейках с фиксированной точностью курсов, интерфейс округляет до рублей.

**Это не полная смета переезда.** Перелёт, виза, страхование и лечение, депозит, обустройство, одежда, развлечения, дети, питомцы и налоги не включены. Статус «На жизнь и резерв хватает» относится только к указанному сценарию. Фактические цены и комиссии обмена могут отличаться. Бюджет не подтверждает право въезда/пребывания.

## Автоматические источники

- [Nomadlio](https://nomadlio.com/): девять публичных страниц `/CITY/cost-of-living/`. Собираем только фактические числовые ориентиры выбранных категорий с атрибуцией; не копируем статьи, изображения или пользовательские данные. Парсер проверяет город, USD, дату страницы и наличие всех обязательных компонентов. Продуктовая и транспортная корзины имеют явный состав; суммы считаются из цен единиц, а не из непрозрачного общего бюджета сайта.
- [Da Nang Apartments](https://danangapartment.net/): приоритетный источник аренды Дананга, медиана не более шести актуальных объявлений квартир с одной спальней из первой страницы каталога. Требуется минимум три разных URL, фиксированная месячная цена, доступность и совпадение города. Это ограниченная выборка, не средняя по городу; для других городов используется ориентир аренды вне центра Nomadlio.
- [VNPT / VinaPhone](https://vnpt.vn/di-dong/vip199/): выбранный опубликованный тариф VIP199, приоритет для двух городов Вьетнама. Условия подключения и ограничения указаны рядом с источником. Это тариф, не средняя стоимость всех операторов.
- [Банк России](https://www.cbr.ru/development/SXML/): курсы валют с учётом номиналов. [Bank Negara Malaysia](https://www.bnm.gov.my/exchange-rates): дополнительный кросс-курс MYR. Это справочные курсы, не курсы конкретного обменника.

У каждой цены: `kind`, `amount`, `currency`, `sourceUrl`, `sourceDate`, `checkedAt`, `basis`, `period`, `note`; при наличии — `components` или `evidence`. У городского ориентира `samples: null`: источник не раскрывает число наблюдений. Дата обновления страницы **не означает свежесть каждого исходного наблюдения**. Тариф не получает выдуманную дату изменения; вместо неё сохраняется дата успешной проверки.

Проверка настроена дважды в день в GitHub Actions, в 05:23 и 14:23 UTC. Запуск может задерживаться или отключаться GitHub при неактивности репозитория. На нажатие кнопки браузер загружает последний опубликованный снимок без кеша; не сканирует сайты заново для каждого посетителя.

Проверка цены должна быть не старше 7 дней, дата источника — не старше 45 дней; у официального тарифа используется проверка страницы. Курсы старше 7 дней блокируют расчёт. При неполных данных город не получает сумму или положительный статус. Ошибка источника сохраняет предыдущую цену и её исходную дату; часы не «освежают» старые данные. Неудача одного города не мешает обновить остальные. Прямые тарифы и объявления сохраняют приоритет, в том числе собственную дату при сбое; устаревший приоритетный источник блокируется, а не маскируется новым ориентиром.

Дополнительный адаптер Numbeo оставлен для владельца с собственной лицензией. Он работает только при `NUMBEO_API_KEY` и `NUMBEO_DISPLAY_LICENSE_CONFIRMED=true`; сейчас для покрытия девяти направлений не требуется. Платный доступ не приобретался.

## Запуск и проверка

Node.js 22+; зависимостей нет.

```sh
npm test
npm start
npm run update-data
```

Локальная страница: `http://127.0.0.1:4173/`. Тесты проверяют денежную арифметику, независимость городов, нулевой доход, обязательства, запас, резерв, неполные/устаревшие цены, валидацию страниц и сохранение дат при сбое.

`src/scenarios.mjs` связывает свежие источники и фиксированный сценарий с денежным ядром `src/calculate.mjs`. `scripts/city-references.mjs` собирает международные ориентиры, `scripts/public-sources.mjs` — прямые источники Вьетнама. `scripts/update-data.mjs` обновляет снимки атомарно. При сбое сообщает ненулевой код, сохраняя успешные обновления.

## Публикация и бренд

GitHub Pages публикуется после push в main, вручную и после обновления данных. В настройках репозитория Pages должен использовать GitHub Actions; переменная `ENABLE_GITHUB_PAGES=true`. Перед публикацией запускаются тесты. В сайт попадают только HTML, CSS, публичные модули, снимки данных и assets; скрипты сборщиков и секреты не публикуются в артефакт Pages.

Графитовый фон, белые карточки, лаймовые акценты и изображение BUCAZU предоставлены владельцем. Вёрстка рассчитана на узкие экраны, поля не меньше 16 px, стрелки списков с внутренним отступом. Цена и детализация доступны без дополнительных полей ввода.
